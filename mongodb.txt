MongoDB is the database used in the MERN stack. Its job is to store, retrieve, update, and delete data.

What is MongoDB?

MongoDB is a NoSQL database that stores data in documents (JSON-like format) instead of tables and rows.

Think of it as a digital storage room for your application's data.

For example, if you're building an Instagram-like app, MongoDB stores:

User information
Posts
Comments
Likes
Followers

Without a database, your app would lose all data when it stops running.

1. Database

A database contains multiple collections.

Example:

Instagram
2. Collection

A collection stores similar documents.

Examples:

Users
Posts
Comments
Orders
Products

Like a folder containing similar files.

3. Document

A document is one record.

Example:

{
  "name": "Prince",
  "age": 21,
  "city": "Mumbai"
}

This is similar to one row in SQL.

4. Fields

Fields are the individual pieces of data.

{
  "name": "Prince",
  "age": 21,
  "city": "Mumbai"
}

Here,

name
age
city

are fields.

Why is MongoDB called NoSQL?

SQL databases use tables.

Users Table

ID | Name | Age
----------------
1  | Prince | 21
2  | Rahul  | 22

MongoDB uses documents.

{
  "_id": 1,
  "name": "Prince",
  "age": 21
}

No fixed table structure is required.

Flexible Schema

Suppose User 1 has

{
  "name": "Prince",
  "age": 21
}

User 2 can have

{
  "name": "Rahul",
  "age": 22,
  "hobby": "Gym"
}

Different documents in the same collection can have different fields. This flexibility is one of MongoDB's biggest advantages.

CRUD Operations

Every database mainly performs four operations.

Create

Insert data.

db.users.insertOne({
    name: "Prince",
    age: 21
});
Read

Get data.

db.users.find();
Update

Modify existing data.

db.users.updateOne(
    { name: "Prince" },
    { $set: { age: 22 } }
);
Delete

Remove data.

db.users.deleteOne({
    name: "Prince"
});
