MongoDB is the database used in the MERN stack. Its job is to store, retrieve, update, and delete data.

What is MongoDB?

MongoDB is a NoSQL database that stores data in documents (JSON-like format) instead of tables and rows.

Think of it as a digital storage room for your application's data.

For example, if you're building an Instagram-like app, MongoDB stores:

User information
Posts
Comments
Likes
Followers

Without a database, your app would lose all data when it stops running.

Real-Life Example (Library)

Imagine a library.

Library → Database
Bookshelf → Collection
Book → Document
Pages → Fields

Example:

Library (Database)
│
├── Users (Collection)
│      ├── Prince
│      ├── Rahul
│
├── Posts (Collection)
│      ├── Post 1
│      ├── Post 2
│
└── Comments (Collection)

1. Database

A database contains multiple collections.

Example:

Instagram
2. Collection

A collection stores similar documents.

Examples:

Users
Posts
Comments
Orders
Products

Like a folder containing similar files.

3. Document

A document is one record.

Example:

{
  "name": "Prince",
  "age": 21,
  "city": "Mumbai"
}

This is similar to one row in SQL.

4. Fields

Fields are the individual pieces of data.

{
  "name": "Prince",
  "age": 21,
  "city": "Mumbai"
}

Here,

name
age
city

are fields.
