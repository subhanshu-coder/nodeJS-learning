Middleware is one of the most important concepts in Express.js. If you understand middleware well, you'll understand how Express handles every request.

What is Middleware?

A middleware is a function that runs between receiving a request and sending a response.

Think of it as a checkpoint.

Client
   │
   ▼
Request
   │
   ▼
Middleware 1
   │
   ▼
Middleware 2
   │
   ▼
Middleware 3
   │
   ▼
Route Handler
   │
   ▼
Response
   │
   ▼
Client

Every request passes through middleware before reaching the final route.

    console.log("Middleware executed");
    next();
