Middleware is one of the most important concepts in Express.js. If you understand middleware well, you'll understand how Express handles every request.

What is Middleware?

A middleware is a function that runs between receiving a request and sending a response.

Think of it as a checkpoint.

Client
   │
   ▼
Request
   │
   ▼
Middleware 1
   │
   ▼
Middleware 2
   │
   ▼
Middleware 3
   │
   ▼
Route Handler
   │
   ▼
Response
   │
   ▼
Client

Every request passes through middleware before reaching the final route.

Middleware Syntax
function middleware(req, res, next) {
    console.log("Middleware executed");
    next();
}

There are 3 parameters.

1. req (Request)

Contains information sent by the client.

Example

req.url

Output

/profile
req.method

Output

GET
2. res (Response)

Used to send data back.

res.send("Hello")

Response ends here.

3. next()

This is the most important part.

It tells Express:

"I'm done. Go to the next middleware or route."

Without it, Express stops.

Example 1
const express = require("express");

const app = express();

app.use((req, res, next) => {
    console.log("Middleware");
    next();
});

app.get("/", (req, res) => {
    res.send("Home");
});

app.listen(3000);

Why?

Because Express waits for either:

next(), or
res.send(), res.json(), res.end(), etc.

Since neither happened, the request never finishes.

Middleware Can End the Request

Instead of calling next():

app.use((req, res) => {
    res.send("Blocked");

Middleware Can Modify Request

    req.user = {
        name: "Prince"
