Middleware is one of the most important concepts in Express.js. If you understand middleware well, you'll understand how Express handles every request.

What is Middleware?

A middleware is a function that runs between receiving a request and sending a response.

Think of it as a checkpoint.

   ▼

   │
   ▼

Every request passes through middleware before reaching the final route.

Middleware Syntax
function middleware(req, res, next) {
    console.log("Middleware executed");
    next();
}

There are 3 parameters.

1. req (Request)

Contains information sent by the client.

Example

req.url

Output

/profile
req.method

Output

GET
2. res (Response)

Used to send data back.

res.send("Hello")

Response ends here.

3. next()

This is the most important part.

It tells Express:

"I'm done. Go to the next middleware or route."

Without it, Express stops.

Error Middleware

Error-handling middleware has 4 parameters.

app.use((err, req, res, next) => {
    console.error(err);
    res.status(500).send("Something went wrong");
});

Express recognizes it as an error handler because of the extra err parameter.

Types of Middleware
Application middleware – runs for many or all routes.
app.use(...)
Route middleware – runs only for specific routes.
app.get("/profile", auth, handler)
Built-in middleware – provided by Express.
express.json()
express.static()
Error middleware – handles errors.
(err, req, res, next)

Key Points to Remember
Middleware is a function that executes before the route handler.
It has the signature (req, res, next).
req contains request data.
res is used to send the response.
next() passes control to the next middleware or route.
If you call res.send(), the request ends.
If you call neither next() nor a response method, the request hangs.
Middleware is commonly used for authentication, authorization, logging, validation, parsing JSON, serving static files, and error handling.

If you're learning MERN, middleware is used constantly—for example:

middleware work as a middle man between software and client , client passing the request and middleware process it then repond to users command 
Express uses middleware to process requests.
JWT authentication is implemented as middleware to verify logged-in users.
Validation middleware checks request data before it reaches your business logic.
Logging middleware records incoming requests for debugging or monitoring
